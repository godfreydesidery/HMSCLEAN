# Architecture documentation

This folder will contain Architecture Decision Records (ADRs) and design notes
as the rewrite progresses.

## ADRs

ADRs follow the format:

- `NNNN-short-title.md` (zero-padded sequence number)
- Sections: Status / Context / Decision / Consequences

Use `0001-modular-monolith.md`, `0002-jwt-auth.md`, etc.
